# 数据集文件

MCP 的最小实例数据集是第 23 课的零售经营库 `lesson23_business_analysis.sqlite`（约 21 MB，不进 git）。放到本目录或用 `KNOWBASE_DATASET_PATH` 指到别处：

```
cp <lessons>/23_Trace与可观测性——从问数Demo到运行事实/resources/data/lesson23_business_analysis.sqlite datasets/
```

数据版本取库里 `dataset_metadata.data_snapshot_id`（`lesson23-analysis-b7ad59fddab30331`）；评测真值引用同一版本（F-KNOW-07）。
